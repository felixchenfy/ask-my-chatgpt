# Community guidelines

We welcome contributors with different backgrounds and levels of experience.
Be respectful, explain disagreements with evidence, and make feedback useful.
Critique code and ideas rather than attacking people. Harassment, discrimination,
threats and disclosure of someone else's private information are not acceptable.

These expectations apply to repository issues, pull requests and other project
spaces. Maintainers may edit or remove harmful content, close discussions or
restrict participation when necessary. If you disagree with a moderation decision,
ask for clarification respectfully rather than escalating the conflict.

Report concerns to the maintainer through an existing private channel. If none is
available, request a private contact route in an issue without naming affected
people or posting sensitive details. There is no promised response deadline.
